Webpage developed by Tricia Wittsack.

This website will search the GIPHY website using the API for GIFs matching 
an input text.

You can copy the URL of any GIF in the results by right-click and selecting 
Copy image address.  Other options on the pop-up menu from the right-click on 
the GIF, are open in a new tab, save, copy and create a QR code options.

Webpage created using HTML, CSS, and Javascript.

 **User Stories:**

 - As a user, I want to be able to to type in text to find matching GIFs from GIPHY.
 - As a user, I want to click on submit to submit my search criteria.
 - As a user, I want to view GIFs that match search string.

 - As a developer of the webpage, I want to be able to detect when the submit is clicked.
 - As a developer of the webpage, I want to capture the user input.
 - As a developer of the webpage, I want  to use the user input in the GIPHY api call.
 - As a developer of the webpage, I want to parse the response from the api.
 - As a developer of the webpage, I want to display the response GIFs in a CSS grid on the webpage.
